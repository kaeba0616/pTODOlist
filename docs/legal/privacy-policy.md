# 하루나무 개인정보처리방침

**시행일**: 2026-10-11

하루나무(이하 "앱")는 매일의 루틴과 할 일을 기록하는 개인용 습관 트래커입니다.
앱은 로그인 없이 모든 기능을 사용할 수 있으며, 이 경우 모든 데이터는 사용자의 기기에만 저장됩니다.

## 1. 수집하는 정보

### 로그인하지 않은 경우
- 어떤 개인정보도 외부로 전송하지 않습니다. 루틴, 할 일, 일일 기록, 설정은 기기 내부 저장소에만 보관됩니다.

### Google 계정으로 로그인한 경우 (선택)
클라우드 백업과 기기 간 동기화를 위해 다음 정보가 Google Firebase(Firestore) 에 저장됩니다.
- Google 계정 식별자(UID), 이메일, 이름, 프로필 사진 URL
- 사용자가 입력한 닉네임
- 루틴, 카테고리, 할 일, 일일 완료 기록

위치 정보, 연락처, 기기 식별자, 광고 식별자는 수집하지 않습니다.

## 2. 이용 목적
- 기기 변경·재설치 시 데이터 복원
- 여러 기기에서 같은 데이터 사용

수집한 정보는 광고, 분석, 제3자 마케팅에 사용하지 않습니다.

## 3. 보관 및 삭제
- 데이터는 사용자가 삭제하거나 계정 삭제를 요청할 때까지 보관됩니다.
- 앱에서 로그아웃하면 기기의 로컬 데이터가 삭제됩니다.
- 클라우드 데이터 전체 삭제는 아래 문의처로 요청하면 7일 이내에 처리합니다.

## 4. 제3자 제공 및 처리 위탁
- 데이터 저장과 인증을 위해 Google LLC 의 Firebase 서비스를 이용합니다. (Firebase 개인정보처리방침: https://firebase.google.com/support/privacy)
- 그 외 제3자에게 개인정보를 제공하지 않습니다.

## 5. 권한
- 알림(POST_NOTIFICATIONS): 사용자가 설정한 시간에 미완료 항목을 알리기 위해서만 사용합니다.
- 저장소 접근: 사용자가 직접 백업 파일을 내보내거나 가져올 때만 사용합니다.

## 6. 아동의 개인정보
앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
