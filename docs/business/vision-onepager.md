# 하루나무 (pTODOlist) - Vision One-Pager

## 한 줄 미션
> 매일 하나씩 쌓아 올려 습관이 자라는 — 심플한 올인원 습관 트래커

---

## 문제 정의
- 매일 해야 하는 일(루틴)을 머릿속으로만 관리하면 빠뜨리기 쉬움
- 기존 TODO 앱은 일회성 할 일에 초점 → 반복 루틴 관리에 부적합
- 습관 트래커 앱은 기능이 많고 복잡하여 오히려 사용을 포기하게 됨
- 하루가 끝나기 전 남은 일을 알려주는 기능이 부족
- 폰을 바꾸거나 앱을 지우면 쌓아온 기록이 사라짐

## 솔루션
- **매일 루틴 + 요일별 활성화**: 매일 / 평일 / 주말 / 특정 요일에 자동 활성
- **추가 할 일 + 마감일**: 일회성 태스크와 overdue 표시
- **카테고리 + subtask**: 운동, 공부, 업무 등 그룹화 + 세부 항목
- **자정 자동 초기화**: DailyRecord 패턴으로 매일 새로 시작
- **시각화**: 일/주/월 통계 + 캘린더 히트맵 + Android 홈 위젯
- **스마트 알림**: 11시 미완료 항목만 (전부 완료 시 무음)
- **선택적 클라우드 백업**: Google 로그인 시 기기 변경·재설치에도 기록 유지, 멀티 디바이스

## 타겟 유저
- 매일의 루틴을 꾸준히 실천하고 싶은 개인
- 복잡한 앱보다 심플한 체크리스트를 원하는 사람
- 자기 관리/습관 형성에 관심 있는 20~40대
- 쌓아온 기록을 잃고 싶지 않지만, 가입부터 강요받긴 싫은 사람

## 핵심 가치
1. **심플함**: 열면 바로 오늘의 할 일이 보임
2. **자동화**: 자정 리셋 + 11시 스마트 알림 — 매일 새로 시작
3. **시각화 + 모티베이션**: 통계 + 캘린더 히트맵 + 위젯으로 "자라는" 기록을 눈으로 확인
4. **유연한 시작**: 로그인 없이도 100% 동작 — 원하면 Google 로그인으로 백업 + 멀티 디바이스 (프라이버시 옵션 유지)

## 차별화 포인트
| 기존 앱 | 하루나무 |
|---|---|
| 서버/가입 필수 | 가입 없이도 100% 동작 + Google 로그인은 옵션 |
| 기능 과다 (팀, 프로젝트, 반복설정 등) | 핵심 (루틴/할일/통계/위젯/캘린더) 만 |
| 수동 초기화 | 자정 자동 초기화 |
| 알림 = 고정 시간 리마인더 | 스마트 알림 = 남은 일이 있을 때만 |
| 로컬 전용이거나 서버 전용 | 둘 다 — 로컬로 시작, 원할 때 백업 |
